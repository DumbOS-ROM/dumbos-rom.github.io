SYSTEM ARCHITECTURE

Built inside the source tree, not bolted on top.

Every visual surface and memory optimization compiles directly into the ROM across Android 13, 14, and 15. Device kernels stay untouched so existing LineageOS device trees boot cleanly.

LAUNCHER & RECENTS-97 MiB RAM

Single-Process DumbLauncher

Replaces TrebuchetQuickStep and Launcher3 with a native Java text launcher and built-in RecentsActivity routed straight from SystemUI.

PARTNER_GMS-180 MiB /system

Target-Arch GmsCore Stripping

Strips unused x86, x86_64, and arm64 libraries from microG GmsCore.apk at build time via Soong zip2zip so legacy partitions never overflow.

SYSTEMUI & SETTINGS#000000 OLED

Monochrome Monet & Settings

Defaults ThemeOverlayController to Style.MONOCHROMATIC, disables GPU window blur, and ships a matching OLED Settings UI with the DumbOS ROM card.

DUMBOS-MODE0 MB DAEMON

4 Hardware Priority Modes

Switches between Normal, Focus DND, Calls & SMS radio cutoff, and SurfaceFlinger Daltonizer grayscale via shell and Quick Settings tile without background polling.

MICROG FCM-USER BUILDS

Production Signature Spoofing

Permits certificate-pinned microG package spoofing inside ComputerEngine.java on -user release builds so WhatsApp push works out of the box.

LOW-RAM TUNINGBOOT SAFE

Safe Fonts & Native LMKD

Ships OnePlus Slate fonts without 75 MB CJK tables, guards FontManagerService against boot deadlocks, and preserves native vmpressure on Linux 3.4–3.18 kernels.

DEVICE MAINTAINERS

          
Optional Kernel Defconfig Tuning

          

            DumbOS never overrides your device kernel. Maintainers targeting 1–2 GB RAM hardware can apply these defconfig recommendations from KERNEL_RECOMMENDATIONS.md:
          


          

            

              
1. Strip Heavy Kernel Debug Overhead

              
Unset CONFIG_SLUB_DEBUG, CONFIG_DEBUG_KERNEL, and CONFIG_SCHED_DEBUG on release builds to eliminate slab allocation stalls on dual-core CPUs.

            

            

              
2. Use LZ4 for ZRAM Swap

              
Enable CONFIG_ZRAM=y, CONFIG_CRYPTO_LZ4=y, and CONFIG_ZRAM_DEF_COMP_LZ4=y for low-CPU page compression.

            

            

              
3. PSI vs Legacy vmpressure

              
Use CONFIG_PSI=y on Linux 4.14+. On Linux 3.4, 3.10, and 3.18, leave PSI off; DumbOS keeps ro.lmk.use_psi unset to avoid kswapd0 thrashing.
