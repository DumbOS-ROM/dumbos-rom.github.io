# DumbOS Official Website (`dumbos-rom.github.io`)

Official website and interactive monochrome OLED simulator for **DumbOS**, deployed via GitHub Pages at:

- **Live URL**: [https://dumbos-rom.github.io/](https://dumbos-rom.github.io/)
- **Organization**: [https://github.com/DumbOS-ROM](https://github.com/DumbOS-ROM)

## Structure

- `index.html` — Landing page, interactive 6-pane DumbOS device simulator, architecture overview, and `repo init` build command generator.
- `styles.css` — Pure `#000000` OLED monochrome stylesheet.
- `app.js` — Interactive phone simulator (Bootanimation, Lockscreen, DumbLauncher Home, A-Z Drawer, Single-Process Recents, OLED Settings & About DumbOS Hero Card) and build configurator.
- `assets/` — Official DumbOS logo, SVG favicon, and OpenGraph social card.
